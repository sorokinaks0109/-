# Ballet Forever

Учёт абонементов и посещений для преподавателя балета. Один файл `index.html`, работает в браузере телефона, данные хранятся на самом телефоне.

## Что умеет

- **Главная**: ближайшее занятие, у кого абонемент скоро закончится, у кого уже закончился.
- **Занятие**: отметить, кто пришёл. С абонемента списывается одно занятие, без абонемента записывается разовое.
- **Ученицы**: карточка с остатком, сроком, историей посещений и оплат. Заморозка по уважительной причине (больничный, командировка, отпуск) сдвигает срок.
- **Деньги**: сколько получено за месяц, сколько занятий сгорело.
- **Настройки**: цены, расписание, текст напоминания, резервная копия.

## Правила абонемента

- Абонемент = N раз в неделю × число недель (обычно 4). Цена по умолчанию 500 ₽ за занятие, разовое 1000 ₽, обе меняются в настройках.
- Действует с даты начала на число недель. Каждое посещение списывает одно занятие, даже если в неделю пришла чаще.
- Заканчивается, когда кончились занятия или прошёл срок. Неиспользованные занятия сгорают.
- Заморозка продлевает срок на число дней заморозки.

## Как поставить на телефон

1. Включить GitHub Pages: Settings → Pages → Deploy from a branch → ветка с `index.html`.
2. Открыть ссылку на телефоне и выбрать «Добавить на главный экран».

Данные живут только в браузере этого телефона. Раз в пару недель сохраняйте копию в настройках.
