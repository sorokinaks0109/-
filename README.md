# Ballet Forever

Учёт абонементов и посещений для преподавателя балета и приложение для учениц.

- **Преподаватель** (`/`): неделя с расписанием и списком тех, кто собирается прийти; отметка посещений в одно касание; заявки от учениц (оплата, пропуск по уважительной причине, новая ученица); ученицы; деньги за месяц; настройки абонементов и реквизитов.
- **Ученица** (`/me/?t=личный-код`): сколько занятий осталось и до какого числа; постоянные дни; «не приду» и «приду дополнительно» на ближайшие занятия; «я оплатила» (переводом или наличными); «пропущу по уважительной причине» с фото документа. Вход не нужен.
- **Новые ученицы** приходят по общей ссылке-приглашению (`/me/?join=код`): пишут имя, преподаватель принимает заявку.

Фото документов удаляются с сервера сразу после решения преподавателя и в любом случае через 14 дней.

Без заполненного `config.js` работает демо: выдуманные ученицы и заявки, данные только в этом браузере.

Сборки нет: обычные файлы, которые публикуются через GitHub Pages.

## Правила абонемента

- Абонемент — это N раз в неделю × число недель (обычно 4). По умолчанию 500 ₽ за занятие, разовое 1000 ₽. Обе цены меняются в настройках.
- Действует с даты начала на число недель. Каждое посещение списывает одно занятие, даже если в неделю пришла чаще.
- Заканчивается, когда кончились занятия или прошёл срок. Неиспользованные занятия сгорают.
- Заморозка (больничный, командировка, отпуск) продлевает срок на число дней заморозки.

## Как запустить

### 1. Supabase (сервер с базой)

1. Зайдите на https://supabase.com и создайте новый проект **New project** (регион: Central EU / Frankfurt). Пароль базы запишите.
2. **SQL Editor → New query**: вставьте целиком файл `supabase/schema.sql` и нажмите **Run**.
3. **Project Settings → API**: скопируйте **Project URL** и ключ **anon / publishable**.
4. Впишите их в файл `config.js`:
   ```js
   window.BF_CONFIG = {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseKey: 'eyJ...',
   };
   ```
   Эти два значения публичные, их можно хранить в репозитории. Секретный ключ `service_role` сюда **не вписывать**.
5. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**, чтобы преподаватель вошёл сразу после регистрации.
6. Откройте приложение, нажмите «Первый раз? Создать аккаунт», введите почту и пароль преподавателя.
7. После этого в **Authentication → Sign In / Providers** выключите **Allow new users to sign up**, чтобы больше никто не зарегистрировался.

Бесплатный проект Supabase засыпает, если им не пользуются 7 дней. Здесь им пользуются каждую неделю, так что это не страшно. Если всё же уснул: панель Supabase → проект → **Restore**.

### 2. Публикация

1. Репозиторий → **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Через минуту сайт откроется по адресу из Settings → Pages.

### 3. Свой домен

Есть два варианта:

- **Поддомен уже купленного домена**, например `ballet.murfografia.ru`. У регистратора домена добавить запись `CNAME`: имя `ballet`, значение `sorokinaks0109.github.io`. Затем в Settings → Pages → Custom domain вписать `ballet.murfografia.ru` и включить **Enforce HTTPS**.
- **Отдельный домен**, например `balletforever.ru`. У регистратора добавить четыре записи `A` на адреса GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Дальше так же: Custom domain и Enforce HTTPS.

### 4. Ученицам

Вкладка «Ученицы» → «Пригласить учениц»: готовое сообщение со ссылкой-приглашением для общей группы в Максе. Каждая открывает ссылку и пишет имя, заявка приходит во вкладку «Заявки». Личную ссылку конкретной ученицы можно отправить из её карточки.

## Что где лежит

- `index.html`, `assets/app.js`: приложение преподавателя.
- `me/index.html`, `assets/me.js`: страница ученицы.
- `assets/core.js`: правила абонемента и вид страницы ученицы, общие для обеих частей.
- `assets/store.js`: хранение. С заполненным `config.js` данные на сервере, а в телефоне копия для работы без интернета. С пустым `config.js` всё хранится только в браузере (демо-режим с примерами).
- `supabase/schema.sql`: таблицы `studio` (данные студии одним документом), `student_days` (постоянные дни), `intents` (не приду / приду), `requests` (заявки с фото) и функции для учениц, которые работают только по личному коду и отдают только её данные.
- `assets/ballerina.svg`, `icons/`: рисунок и значки приложения.
- `vendor/supabase.js`: библиотека Supabase, лежит в репозитории, чтобы не зависеть от сторонних серверов.
